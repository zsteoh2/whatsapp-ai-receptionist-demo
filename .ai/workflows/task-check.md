# Task Check

1. Set stage to `verification`.
2. Review the request, requirements, business rules, plan, diff, and architecture without assuming the implementation is correct.
3. Run applicable build, tests, lint/static analysis, and manual validation.
4. Record every result in `verification.md` as `passed`, `failed`, `not run`, `not available`, or `blocked`.
5. Return failures to implementation. When checks are sufficient, set stage to `documentation` and continue with `task-finish.md`.
