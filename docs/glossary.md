# Glossary

| Term | Meaning |
|---|---|
| ORA | Reusable presentation identity for the business owner's WhatsApp virtual assistant. |
| Cleaner Demo | Hidden ORA presentation mode entered only with the exact standalone `cleaner` command; it does not yet contain an approved cleaner catalogue or booking process. |
| Legacy Clinic template | Retained, regression-tested business example that is disabled by default and not customer-accessible in ORA-only mode. |
| Clinic Reception Team | Fictional handover destination used only inside the disabled legacy Clinic template. |
| Confirmed booking | Stripe test payment completed and Google Calendar event successfully created. |
| Handover | Automation is paused and a safe, minimal reason is logged for human review. |
| Test deposit | Stripe Test Mode payment of £10, £20, or £30; no real money. |
