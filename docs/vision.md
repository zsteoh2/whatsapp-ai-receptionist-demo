# Vision

Build a credible, safe demonstration of a WhatsApp receptionist for an appointment-based aesthetic clinic. A prospect should be able to see FAQ answering, booking-data collection, live calendar availability, test payment, calendar creation, confirmation, and human handover in one English conversation.

The product is a demonstration for scheduled or recorded presentations. It is not a production clinic system and must not present fictional business data as belonging to the reference clinic.
